# Countdown to Hiroshima — процедурное видео на JS (Three.js + Canvas + Web Audio)

Видео 16:9, 1920×1080, 30 fps, длительность = длительности озвучки (~17:43).
Каждый визуальный бит привязан к **таймингу слова** из `assets/narration.json` (whisper), поэтому картинка
меняется ровно в момент, когда диктор произносит слово.

## Быстрый старт
```bash
npm install                 # three, puppeteer (скачает Chrome), ffmpeg-static, шрифты, d3-geo
npm run preview             # http://localhost:5173  — превью в реальном времени с озвучкой и SFX
npm run render              # полный рендер → out/hiroshima_countdown.mp4
```

## render.js
```bash
node render.js                                 # весь фильм
node render.js --workers 3                     # параллельно (каждый воркер — свой Chrome)
node render.js --start 400 --end 480 --out out/attack.mp4   # фрагмент
node render.js --stills 5,60,430               # PNG-кадры в out/stills/
# --fps 30  --crf 17  --captions 0 (без субтитров)  --no-audio  --sfx-gain 0.7  --chunk 30
# env: CHROME_PATH=путь_к_chrome  FFMPEG_PATH=путь_к_ffmpeg
```
- Рендер детерминированный (кадр = функция времени), кусками по 30 с в `out/*_chunks_*/` — прерванный рендер
  продолжается с места остановки.
- Звук: все SFX синтезируются Web Audio в `OfflineAudioContext` прямо в странице, сохраняются в WAV и
  микшируются под голос (`assets/voice.mp3`) с сайдчейн-приглушением — эффекты тихие и уходят под диктора.
- На машине с видеокартой рендер идёт заметно быстрее (Chrome использует GPU для WebGL).

## Структура
- `src/core` — движок (пост-обработка: bloom, ACES, грейд, зерно, виньетка, хроматика), тайминги слов, текстуры.
- `src/kit` — 3D-ассеты: персонажи с ригом, B-29, Little Boy / Fat Man, процедурные Хиросима и Нагасаки,
  здания (купол Гэмбаку, мост Аиой, собор Ураками, кенотаф), техника, частицы (огонь, дым, гриб, дождь).
- `src/2d` — инфографика, кинетическая типографика, карты (d3-geo), субтитры.
- `src/shots/act1..5.js` — раскадровка: каждый шот = `add(T('фраза из озвучки'), имя, сцена, {sfx, bed})`.
- `src/audio` — синтез звуков (удары, гул B-29, сирена, взрыв, тиканье, морзе, гейгер, колокол, пианино, эмбиент).
- Титры «6 лет до / 1 месяц до / 24 часа до …» — чистый текст на чёрном фоне с ударом и тиканьем часов.

Если поменяете озвучку — замените `assets/voice.mp3` и `assets/narration.json`
(`{words:[[word,start,end],...]}`), затем `node scripts_check_phrases.mjs` проверит, что все фразы-якоря нашлись.
